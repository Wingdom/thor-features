# Screenshots

Used by the main `README.md`. All captured from the author's device.

| File | Shows | Size |
|---|---|---|
| `panel.png` | The AYN button panel on the bottom screen | 1240×1080 |
| `tiles.png` | The stick-LED and fan Quick Settings tiles | 940×150 |
| `appprofiles.png` | The per-game fan profiles app | 1920×1080 |

Captured with `screencap -d <display-id>`, which grabs one panel directly — the
Thor's two screens are separate displays, so no cropping is needed to separate
them. Main is `4630946441858561667` (1920×1080), bottom is
`4630946482288158084` (1240×1080).

`tiles.png` is cropped from a full Quick Settings frame, deliberately: the
untrimmed shot included the Wi-Fi tile showing a network name, which should not
be on a public page. The screenmove tile is not in it because it sits on the
third Quick Settings page on this device, and reordering the tiles to group them
did not survive SystemUI's cached layout.
